# My App

A simple static webpage used to practice Git fundamentals as part of the CI/CD training task sheet.

## What this covers
- Git installation & config
- Local repo init, staging, and commits
- Pushing to a remote (GitHub)
- Branching, making changes, and merging via Pull Request

## Run it
Just open `index.html` in your browser.
